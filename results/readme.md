# `/results/` Directory

This directory contains analytical outputs, model-evaluation artifacts, ranking tables, network files, enrichment results, and final reporting assets generated by the project workflow.

### **Top-Level Results Files**

| File Name | Description | Key Content | Usage |
| --- | --- | --- | --- |
| `differential_expression_results.csv` | Differential expression output comparing tumor and normal expression profiles. | `gene`, tumor/normal means, `log2fc`, `pvalue`, `pvalue_adj`, `cohens_d`, significance, and direction columns. | Starting point for DE filtering, effect-size review, and downstream ranking. |
| `ensemble_soft_vote_probs.csv` | Per-gene prediction scores from the soft-voting ensemble model. | `gene`, `ensemble_prob`. | Use when you want the ensemble probability only, without the full ranking table. |
| `feature_importance.csv` | Cross-model feature-importance summary used for interpretation. | Per-feature ranks, model-specific importances, permutation importance, mean/std importance, and feature groups. | Identifies which engineered features drive the classifier family most strongly. |
| `gene_rankings.csv` | Main integrated gene-prioritization table. | Prediction probability, final rank, DE statistics, novelty flags, query flags, and selected annotation columns. | Primary file for candidate review and ranked follow-up. |
| `model_metrics.csv` | Holdout evaluation summary for each trained model and the ensemble. | AUROC, AUPRC, Brier score, fixed-threshold metrics, oracle metrics, optimal threshold, recall-at-K, and precision-at-K. | Compare model behavior and choose the scoring strategy appropriate for your use case. |
| `novel_candidates.csv` | Prioritized non-LCGene candidate list derived from the integrated ranking. | High-probability genes with novelty filtering applied. | Main list of putative novel biomarkers or targets. |
| `novel_candidates_sensitivity.csv` | Sensitivity-analysis view of novel candidates under the broader novelty flag. | Same core ranking columns as `gene_rankings.csv`, plus `novel_candidate_sens`. | Use when you want a less strict sensitivity screen around novelty labeling. |
| `pu_bagging_metrics.csv` | Positive-unlabeled bagging run summary. | PU training configuration, validation AUROC/AUPRC, top-K recall, precision-at-K, and novel-candidate counts. | Documents the bagging setup that generated the ranking probabilities. |
| `pu_bagging_scores.csv` | Per-gene probabilities from the PU bagging stage before final ranking/export steps. | Gene-level PU scores for the unlabeled pool. | Useful for debugging or re-deriving downstream ranking exports. |
| `query_gene_rankings.csv` | Optional filtered export for a user-supplied query gene set. | Currently an empty placeholder file in this folder. | Populate or regenerate when query-specific ranking output is needed. |
| `ranking_metrics.csv` | Compact ranking-performance summary for the final prioritization output. | Median LCGene rank, top-K recovery counts, recall-at-K, precision-at-K, novel count, and PU framing indicator. | Quick read on how well known positives are recovered by the final ranked list. |

### **`/classification_reports/` Subdirectory**

Contains plain-text classification summaries for each trained model at the reporting threshold.

| File Name | Description | Usage |
| --- | --- | --- |
| `classification_report_ensemble_soft_vote.txt` | Precision/recall/F1 report for the soft-voting ensemble. | Best quick read for the ensemble's class-specific behavior. |
| `classification_report_xgboost.txt` | Class-wise classification report for calibrated XGBoost. | Inspect XGBoost precision/recall tradeoffs beyond scalar metrics. |
| `classification_report_random_forest.txt` | Class-wise classification report for calibrated Random Forest. | Review thresholded performance for the forest model. |
| `classification_report_gradient_boosting.txt` | Class-wise classification report for calibrated Gradient Boosting. | Useful when comparing recall-heavy behavior against other models. |
| `classification_report_extra_trees.txt` | Class-wise classification report for calibrated Extra Trees. | Useful when comparing strong AUPRC/F1 behavior to the ensemble. |
| `classification_report_logistic_regression.txt` | Class-wise classification report for the linear baseline. | Baseline reference for simpler model behavior. |

### **`/network/` Subdirectory**

Contains network construction, annotation, and export files for the co-expression analyses.

#### **Core Network Files**

| File Name | Description | Format & Content |
| --- | --- | --- |
| `coexpression_network.graphml` | Disease-focused co-expression network. | GraphML network used as the basis for annotation and export. |
| `coexpression_network_edges.csv` | Edge-list export of the disease-focused co-expression network. | CSV with source/target pairs and edge weights. |
| `normal_coexpression_network.graphml` | Reference co-expression network built from normal samples. | GraphML network for baseline or comparative analysis. |
| `normal_coexpression_network_edges.csv` | Edge-list export of the normal-sample co-expression network. | CSV companion to the normal GraphML file. |
| `annotated_network.graphml` | Annotated network enriched with model, DE, and network-derived metadata. | GraphML with node-level attributes for downstream visualization and analysis. |
| `annotated_nodes.csv` | Flattened node-attribute table from the annotated network. | CSV for filtering, statistics, and joins with other result tables. |
| `annotated_edges.csv` | Flattened edge-attribute table from the annotated network. | CSV for edge-level analysis and external tooling. |

Companion `*.graphml.xml` files are alternate serialized copies of GraphML exports and can usually be ignored if you are already using the corresponding `.graphml` file.

#### **`/exports/` Subdirectory**

Network files exported in multiple formats for different analysis tools and visualization platforms.

| File Name | Description | Target Tool/Use Case |
| --- | --- | --- |
| `network_cytoscape.json` | Cytoscape-compatible JSON export. | Cytoscape desktop visualization and analysis. |
| `network_full.graphml` | Complete annotated network in GraphML format. | Gephi, yEd, or any GraphML-compatible workflow. |
| `network_full.gml` | Complete annotated network in GML format. | NetworkX, igraph, or other GML-friendly tools. |
| `network_full_edgelist.tsv` | Tab-separated edge list for the full network. | Quick loading in R, Python, or custom scripts. |
| `network_nodes.tsv` | Tab-separated node attribute table. | External joins and statistical analysis. |
| `network_statistics_report.csv` | Machine-readable summary of network statistics. | Automated reporting or downstream scripts. |
| `network_statistics_report.txt` | Human-readable summary of network statistics. | Quick reference for node count, edge count, density, and related properties. |

#### **Subnetwork Exports**

| File Name | Description | Selection Criteria |
| --- | --- | --- |
| `subnetwork_top100.graphml` / `subnetwork_top100_edgelist.tsv` | Top-100 ranked gene subnetwork and matching edge list. | Highest-ranked genes from `gene_rankings.csv`. |

### **Key Analytical Workflows**

1. **Differential Expression + Feature Importance Integration**

   ```
   differential_expression_results.csv -> gene_rankings.csv
   feature_importance.csv -> gene_rankings.csv
   ```
2. **PU Scoring and Model Evaluation**

   ```
   pu_bagging_scores.csv -> gene_rankings.csv / ranking_metrics.csv
   model_metrics.csv + classification_reports/*.txt -> model comparison
   ```
3. **Network-Enhanced Candidate Discovery**

   ```
   coexpression_network.graphml -> annotated_network.graphml -> exports/
   gene_rankings.csv -> novel_candidates.csv -> enrichment/
   ```
4. **Comprehensive Reporting**

   ```
   top-level CSV results + network statistics -> reports/pipeline_report.txt + pipeline_summary_figure.*
   ```

---

### **Usage Guidelines**

- **For Quick Insights**: Start with `pipeline_report.txt`, `model_metrics.csv`, and `ranking_metrics.csv`.
- **For Candidate Selection**: Use `gene_rankings.csv` first, then narrow to `novel_candidates.csv` or `novel_candidates_sensitivity.csv`.
- **For Model Comparison**: Pair `model_metrics.csv` with the matching files in `classification_reports/`.
- **For Network Analysis**: Use `annotated_network.graphml` for integrated analysis and `network/exports/` for tool-specific formats.
- **For Pathway Review**: Use `enrichment/kegg_summary.csv` before opening the larger KEGG result tables.
- **For Query-Specific Exports**: Regenerate or populate `query_gene_rankings.csv` when you need ranks for a custom gene list.

### **File Relationships**

```
differential_expression_results.csv -> feeds ranking and interpretation
feature_importance.csv -> complements ranking and biomarker interpretation
pu_bagging_scores.csv + ensemble_soft_vote_probs.csv -> provide model-derived gene scores
gene_rankings.csv -> source for novel candidate lists, subnetworks, and report tables
annotated_network.graphml -> source for network exports and subnetwork extraction
top-level results + network outputs + enrichment outputs -> compiled into reports/pipeline_report.txt and pipeline_summary_figure.*
```
